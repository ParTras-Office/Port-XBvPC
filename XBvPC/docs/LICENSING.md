# Licensing — explicit decision required

This starter pack intentionally **does not add a `LICENSE`**. Selecting and publishing a license is the repository owner's decision after verifying rights to every included file.

- **MIT:** permissive; requires copyright and permission notice retention.
- **Apache-2.0:** permissive, includes an express patent grant and notice requirements.
- **GPL-3.0:** copyleft obligations apply to distribution of covered combined/derived software.

Confirm third-party attribution, license compatibility, project authorship and any restrictions before choosing. Do **not** automatically copy the license of a reference repository, nor copy source from that repository without meeting its terms. A public GitHub repository without a license does not grant general redistribution rights.
