# Security policy

The project is experimental and has **no security support guarantee** for loading arbitrary untrusted PE images. Do not run unknown binaries assuming this is a secure sandbox. Prefer synthetic test fixtures.

Report security-sensitive problems privately to the repository maintainer (enable GitHub private vulnerability reporting under repository security settings once the repository is set up). Do not publish secrets, credentials, console keys, game files, or proprietary binaries as proof of concept.

Static publication checks are a first pass only; run a dedicated secret scanner and review every file before publishing.
