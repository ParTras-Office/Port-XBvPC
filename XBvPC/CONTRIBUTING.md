# Contributing

Thanks for your interest. This project is an early-stage research lab; a contributor-friendly license and standalone build are still being reviewed. **Do not submit third-party source code or binaries before a license and provenance policy have been established.**

When reporting an issue, include a minimal synthetic reproducer, toolchain and sanitized logs. For fixes, keep changes narrowly scoped, add a failing test first where possible, document expected/actual results and avoid claims about commercial game compatibility without reproducible proof.

No copyrighted games, Xbox keys, proprietary SDK headers, decrypted commercial content, personal information, or instructions to circumvent access controls. See [SECURITY.md](SECURITY.md).
